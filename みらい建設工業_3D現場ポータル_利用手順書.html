1はじめに

1.1このポータルでできること

「みらい建設工業 3D現場ポータル」は、港湾・海岸・陸上土木・港湾建築の工事現場17か所（陸の15か所と、浚渫・海面埋立の2か所。すべて架空）のようすを、実在の港湾地区の街並みの中に3Dで見られるWebページです。7つの支店（北海道・東北・東京・中部・大阪・中国・九州）の現場を、支店をまたいで1つの画面で見られます。

🗾 支店をまたいで全国を見わたす

日本全体の上に現場のピンが立ちます。ピンの色で、工事が予定どおりか、遅れそうかがひと目で分かります。支店を選べば、その支店の現場だけにしぼれます。

🔎 工事番号・港名でさがす

工事番号（仮採番。例：HK-2026-0002）、港名、支店名、工事名、住所などで現場をさがせます。工種区分（港湾・海岸・陸上土木・港湾建築）や発注区分（官公庁・民間）でもしぼれます。

🏗 現場に入る

ピンを選ぶと現場へ飛んでいき、Google の実写3Dの港の中に、工事中の地面・護岸・堤体・舗装・倉庫・重機が現れます。護岸や堤体は水域の側に、工事用ゲートは陸の側に置かれます。

📅 時間を動かす

日付を動かすと、過去（実績）と未来（予測）の現場のようすが3Dで変わっていきます。

🧮 数字で確かめる

掘る土・盛る土・外から運び入れる土（搬入土）の量、重機の能力、冬期の影響、工事がいつ終わりそうかを、表とグラフで見られます。条件を変えて比べることもできます。

🏢 支店ごとにまとめる

左のサマリに、支店ごとの現場数・平均進捗・遅延予測の数がまとまって出ます。工程会議の前の確認に使えます。

1.3使う前に必ず守ること

  1. 架空であることを伝える：画面の工事・発注者は架空です。画面の画像を資料に使うときは「架空の工事（サンプル）」と書いてください。実在の発注者や当社の実工事と取りちがえられないようにします。
  2. 社内限定で使う：このポータルとこの手順書の情報区分は「社内」です。社外の人（発注者・漁協・港湾利用者など）に見せるときは、架空であることをはっきり伝え、DX推進部の了承を先にとります（5.3）。
  3. 左下の表示を消さない：3Dの左下に出る Google のロゴやデータの提供元の表示（帰属表示）は、消したり、画像を切りとって外したりしないでください。
  4. アカウントとパスワードを人に貸さない：アカウントは1人に1つです。パスワードはほかのサービスと使い回さず、メール・チャット・desknet's NEO に書かないでください（社内LAN の http で使っているため、使い回しは特に危険です）。
  5. キーは DX推進部が管理する会社のキーだけを使う：Google の APIキーは DX推進部が発行・管理します。サーバ版ではキーはサーバに置いてあり、利用者が入れる必要はありません。個人のキーや個人の請求先は使いません。キーを受けとった人は、メール・チャット・desknet's NEO の書きこみなどに貼ったり、ほかの人に教えたりしないでください。使った分のお金は会社の請求先に請求されます。

4.8条件を変えて比べる（What-if）

「バックホウを増やしたら、いつ終わる？」「冬期の稼働がもう少し良かったら？」のような試しができます。変えた値はあなたの画面の中だけで使われ、ほかの人の画面やファイルには残りません。ページを読み直すと元にもどります。

  1. 現場を選び、土工計画 タブを開きます。
  2. 「バックホウ（0.7m³級）」「ダンプトラック（10t）」などの数字を変えます。すぐに計算し直され、棒グラフと完了予測が変わります。冬期のある地域の現場では「冬期の土工稼働率」も変えられます。
  3. 左の台帳の遅延の札と、3Dの予測の見え方も変わります。
  4. ワールドモデル タブの比較表（初期計画／現在の a／差）で、最初の計画との差を確かめます。
  5. 元にもどすときは、初期計画に戻す（タブによっては 初期条件に戻す）を押します。

土量算出 タブの「計画地盤高」や、港湾倉庫の「根切り深さ」・産業用地造成の「調整池深さ」を変えると、3Dの地面の形も作り直されます。雨天・休止率や冬期の稼働率の初期値は、都道府県ごとのサンプル値です。

5.1遅れそうな現場を見つけて、原因を確かめる

例として、遅れの予測がいちばん大きい 石狩湾新港 ふ頭用地造成工事（HK-2026-0002）の「+105日」がどこから来ているかを、冬期の稼働率と搬入土の量から確かめます。

  1. チップの 遅延予測 を押します。15日以上遅れそうな現場だけが残ります（下の表の3件）。
  2. 台帳の HK-2026-0002 の行をクリックして現場に入ります。左のサマリで、実績（基準日）24%（計画 26%）、竣工 遅延予測 +105日、予測 2028/02/05（計画工期は 2026/05/11〜2027/10/23）を確かめます。地域条件は「雨天 10%／冬期 12月〜3月（土工稼働 30%）」です。
  3. 工程管理 タブを開きます。「盛土・嵩上げ（土工）」の計画は 2026/08/19〜2027/03/27 で、基準日の時点で約2割（20%）の進み具合です。横棒グラフの青い帯（冬期）が、この土工の期間の後半（12月〜3月）に重なっていることを見ます。
  4. 土量算出 タブを開きます。この現場は現況から1.5m 嵩上げするため、切土は 0 m³、盛土は 48,302 m³（締固め後）です。盛土の材料はすべて外から運び入れる搬入土で、量は 64,403 m³（ほぐし）、取扱土量 Q は 53,669 m³（地山）です。
  5. 土工計画 タブを開きます。ボトルネックは 掘削・積込（バックホウ）、初期の編成はバックホウ 2台・ダンプ 15台・ローラ 1組です。「実効率 η」が 0.48（実績から推定）になっていることも確かめます。土工を終えた現場では 0.8（参考値）なので、それより低い値です。
  6. 冬期の影響を見るため、「冬期の土工稼働率」を 30% から 100% に変えて、竣工予測がどれだけ早くなるかを見ます。見終わったら 初期計画に戻す を押します。
  7. 次に「バックホウ（0.7m³級）」を 2 から 3 に変えて、ワールドモデル タブの比較表で、土工完了と竣工予測の差を見ます。終わったら 初期計画に戻す を押します。

使い終わったら ログアウト を押します。

10新しいタブの使い方

現場を選ぶと、管理パネルに「土量算出・土工計画・施工計画・工程管理・ワールドモデル」（4.7）に続いて、次のタブが並びます。画面の工事・発注者・工程・実績・作業船はすべて架空です。

10.1気象・海象と潮位

  • 気象・海象：現場の地域の天気・風・波（気象庁）と、発表中の警報・注意報。水際の工種では作業判断の目安（波の高さ 注意 1.5m／中止 2.5m。サンプル値）が出ます。台帳の「⚠気象／⚠中止目安」、絞り込みの「気象注意」もこの情報です。いまの実際の予報なので、工程の予測（架空のデータ）には入りません。
  • 潮位：最寄りの潮位表地点（気象庁）の潮位のグラフ、満潮・干潮、干潮時の作業時間帯（平均海面より 20cm 以上低い時間。サンプル値）。1日の潮位を再生 で、3D に潮位面が出て動きます。

10.2作業可能日

  1. 基準のボタンを選びます：ケーソン据付（波 0.8m 以下、潮の変化がゆるやかな時間が日中に4時間）／干潮時の作業（平均海面より 20cm 以上低い時間が日中に2時間）／海上作業（一般）（波 1.2m 以下で日中に6時間）。どれもサンプル値です。
  2. 見る期間（14・30・60日）を選びます。日ごとに「適」「潮位のみ適（波は前日に再確認）」「不適」が出ます。波は気象庁の予報がある約3日間だけ判定し、その先は推測しません。
  3. 右の「候補日」に、その基準に当たる工程の予測の期間の中から、適の日、次に潮位だけ適の日が並びます。
判定は目安です

基準は社内の正式な基準ではありません（サンプル値）。作業を行うかどうかの最終判断は現場の責任者が行ってください。

10.3配船（サーバ版）

  • 上のガントに、作業船ごとの割り当て（全現場）と、今後180日の稼働率が出ます。白い枠の線が、選んでいる現場の割り当てです。海上工事の現場では、浚渫・埋立の予測期間と、編成に対する割り当ての不足日も出ます。
  • 編集者・管理者：「割り当ての追加」で作業船・期間・役割・メモを入れて 保存。一覧の 編集・削除 で変えます。同じ船を同じ期間に別の現場へ割り当てると、保存できず、重なっている割り当てが表示されます。
  • 管理者：「作業船の登録」で自社船・傭船を登録します（所属はいま選んでいる現場）。
  • いまの作業船7隻はデモ（架空の船・架空の動き）です。AIS（船の位置の自動受信）はつながっていません。

10.4測量の比較（サーバ版・海上工事の現場）

  1. 編集者・管理者：「深浅測量の登録」で、測量日・値の種類（標高（T.P.）／標高（DL＝潮位表基準面）／水深（DL から下向きに正））を選び、XYZ／CSV のファイル（経度,緯度,値 または 東m,北m,値）を選んで 取り込んで登録 を押します。DL のときは、DL の T.P. からの高さ（潮位表の値が初期値。無い地点は入力）が必要です。
  2. 「出来形の推移」に、測量日ごとの残り土量・出来高（測量）・余掘り（過盛り）が並びます。
  3. 「比べる測量」で A と B を選ぶと、B の出来形の色分け（浚渫：取り残し／適正／余掘り超過、埋立：不足／適正／過盛り。許容はサンプル値）と、A→B の変化（深くなった・浅くなった m³）が出ます。
  4. ボタン B の海底で土量・工程を計算し直す（この画面だけ）は、いま見ている画面だけで計算し直します。保存されず、ほかの人の画面も変わりません。読み込み直すと元にもどります。

10.5協議・区域（サーバ版）

  • 協議記録：漁協・港湾管理者・海上保安部・発注者・地元などとの協議を、日付・相手先・出席者・内容・合意事項・宿題・状態（対応中／完了）で残します。編集者・管理者が「協議記録の追加」で入れて 保存。
  • 個人の連絡先は書かない：出席者は「○○漁協 組合長」のように組織・役職までにします。メールアドレス・電話番号を書くと保存できません。
  • 作業区域・航路：種類（作業区域・航路・漁業の区域・立入禁止・その他）と名前を入れ、面を描く か 線を描く を押して地図をクリックし、描き終える（保存）。やめるときは やめる。描いた線・面は「区域・航路」レイヤーで全員の地図に出ます。航路は協議に基づく手入力の線で、公式の航路図ではありません。

10.6遅れの分析と遅れの予兆

  • 遅れの分析タブ：竣工予測と、遅れの理由（実績の遅れ・実効率・ボトルネック・冬期・雨天・搬入土）、遅れを取り戻す編成の提案（3案まで）が出ます。試す で What-if に入れて確かめられます（保存しない）。AI による説明文は、DX推進部が有効にしたときだけ出ます。
  • 遅れの推移（サーバ版）：毎朝 7:30 にサーバが記録する正式な予測（What-if は含まない）の遅れの日数のグラフです。
  • 遅れの予兆（サーバ版）：全国表示に、7日以上前の記録と比べて遅れが7日以上ふえた現場、または14日超へ悪化した現場が並びます。記録が7日分たまるまでは判定しません。サンプルの実績は固定なので、実績の入力が無い間は遅れはほとんど変わりません。

10.7類似工事

同じ工種で土量が 0.5〜2 倍の工事の工期・土量・能力・遅延・実効率を、表と散布図で比べます（総合評価部向け）。全国表示のポートフォリオには工種別の平均が出ます。現場は架空の17件なので、統計としての意味はまだありません。

10.8実績入力（編集者・管理者）

  1. 工程ごとの「実績 %」を入れ、必要なら「変更の理由・メモ」を書きます。
  2. 保存と記録 を押すと、サーバに保存され、ログインしている全員の予測・遅延・3D の出来形が変わります。下の「変更の履歴」に、だれが・いつ・何を変えたかが残ります。
  3. 初期値に戻す で、その現場の実績を初期の状態にもどします（履歴は残ります）。

閲覧者は入力できません（「閲覧者のため入力できません」と出ます）。オフライン版・開発用の配信では、入れた実績はこのブラウザの中だけに保存されるデモです（JSON で書き出し・読み込み）。

11会議・説明で使う

11.1会議巡回（📋）

  1. 左の絞り込みで、会議で見る現場（例：自分の支店）にしぼります。
  2. ヘッダーの 📋 会議巡回 を押すと、しぼった現場を遅れの大きい順に自動で回ります。各現場で遅れの分析タブを出します。下の帯で、前・次の現場、一時停止、1現場の時間（10・20・30・60 秒）を選べます。

社外の人に見せるとき

  2. ポートフォリオの 📄 会議資料（PDF） を押します。いまの絞り込みの現場を遅れの大きい順にまとめ、現場ごとに遅れの理由・挽回の案（AI が有効なら説明文も）を付けた資料が作られます。

  • ポートフォリオの CSV 出力：台帳を Excel で開ける CSV で保存します。
  • 現場のサマリの 🖨 現場概要を印刷：A4 の現場概要（基本情報・土量・工程・気象）を印刷します。
