実績

Google 実写3D（Photorealistic 3D Tiles）を使う

現場周辺の街並み・地形を Google の実写3Dで表示します。Google Cloud で発行した Map Tiles API のキーを入力してください。キーはこのブラウザにだけ保存され、ファイルには書き込まれません。

  • キーは API制限：Map Tiles API のみ、アプリ制限：HTTPリファラ（このサイトを https://ホスト名/* の形で） にしてください。
  • 課金の暴走を防ぐため、Cloud Console で 1日あたりのクォータ上限 と 予算アラート を設定してください（無料枠を超えると従量課金）。
  • Google の3Dデータはオンライン表示のみです（保存・キャッシュ・抽出は規約で禁止）。画面左下の帰属表示は消さないでください。
  • 工事・建物計画はすべて架空です。実在の建物・土地とは関係ありません。
